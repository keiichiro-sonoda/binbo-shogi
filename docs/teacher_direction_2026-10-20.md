# 教師の方針 (2026-10-20, 作者との相談の記録)

Task 142 (公開教師データで仕上げると +29.5) のあと, 公開データをどこまで使うか, 自前の教師をどうするかを相談した。決めたことと理由。

## 分かったこと
- **今までのラベルの中身**: 局面は技巧2 の自己対局 (depth 8) から集め, ラベルは WS-T + Gumbel MCTS 8 回。
  WS-T は AlphaZero 方式の自己対局を始めるための最初の教師で, **技巧2 の評価値と最善手を写し取った (蒸留した) 深層学習のネット** (技巧2 との相関 0.96)。
  自己対局ループで技巧2 を超えようとしたが, 外部の物差しではほとんど伸びなかった (Task 091〜099)。
  WS-T のラベルが技巧2 のラベルより良かったのは, WS-T の知識ではなく **MCTS 8 回の先読み** による (Task 098 / 100 / 104)。
  → 今までのラベル = 「技巧2 の知識 + 浅い先読み」。
- **水匠5 のラベルが良い理由**: 方式 (MCTS か αβ か) ではなく, 評価する側の強さ。水匠5 はトップクラスの評価関数で, それを depth 9 まで読ませている。
  自前の教師は物差しとの相関 0.47 (Task 139)。教師が強いほど生徒も強くなる。
- 公開データのデータセットは, それぞれ 1 つの将棋 AI の評価値で付けてある (水匠5 / Hao / tanuki- 2024 年版)。
  **Hao は判定の物差し (tanuki- Háo) と同じ評価関数**なので, それで学習すると物差しに似せることになり, 判定が意味を失う → 使わない。tanuki- 2024 年版も同じ系統なので要注意。

## 作者の懸念と方針
- 公開データ (水匠5) を何倍にも増やすと, binbo は「水匠5 の生徒」に近づき, 「自宅のマシンで独自に学習する」というコンセプトと逆向きになる。
- 一方で, **最初から強い教師で学習した場合 (下駄を履かせた場合) と, 自前で強くしていく場合で, どれくらい差があるかを実感したい** (作者)。
- そこで:
  1. **Task 145 = 水匠5 の生徒を 1 度作る** (比べるための基準。採用を目指すものではない)。水匠5 の学習用データの先頭 6,400 万局面 (自前と同じ量) で,
     自前と同じ形・同じレシピでゼロから学習し, 自前だけ (task129) / 自前 + 水匠5 の仕上げ (task142, 採用中) と同じ物差しで比べる。
  2. **本線は「雑巾絞り」** (自分の探索でラベルを作り, 学習し, 強くなった自分でまたラベルを作る)。今の binbo (やねうら王の探索 + 採用 eval) は WS-T より強いので,
     binbo に深く読ませた評価値は今のラベルより良いはず。すべて自前の流れで, 水匠や tanuki- も同じやり方で強くなってきた。WS-T は「自宅でゼロから教師を作る」最初の一段の役目を果たした, と整理する。
  3. 公開データは「比べるための目安」と「最後の軽い仕上げ」にとどめる (採用中の task142 の 724 万局面の仕上げは続けて使う。大会では使用ライブラリとして申告)。
- 片付け (作者承認): Task 142 の混ぜる案のデータ (33GB) と Task 138 の各周の重み (4GB) を消した。

## その後 (10/21 追記)

- 雑巾絞りの 2 回目 (Task 154): **binbo 自身の自己対局** (15 万局, depth 9, 詰みを読み切るまで指す, 全行に勝敗) で task142 から 2 周仕上げると, 評価値 7 割 + 勝敗 3 割の版が **+28.6 [+14.3, +42.9]** (確認の組でも物差し 2 本・micro とも正)。10/21 に採用 (`task154_R_result30`)。
