# Task 095 — r=1.0 対照: 094 の「+79」は追加 supervised 学習の回収ではなかった

**目的**: Task 094 は anchor 率 r(512 policy update のうち WS-T supervised best-move replay に置き換える割合)を一変数として、093 の外部単調悪化を反転させた(paired ΔElo vs WS-T: r=0 **−74** → r=0.25 **+21.3** → r=0.50 **+79.1**、両arm FLAT)。だが **r=1.0 の対照が無い**と、「+79 は自己対局の寄与」なのか「同じ 2M を追加で回しただけの回収」なのかを**原理的に分離できない**。本タスクは r=1.0(自己対局データを1度も勾配に触れさせない、512 update 全部 supervised)を足し、4点用量反応と、**WS-T が相殺される直接 paired 比較 Δ_selfplay =(r=0.50)−(r=1.00)= 自己対局の限界寄与**を測る。実測 2026-07-29、隔離(experiments/alphazero SSOT)、RUN_META、Rust/champion 不触。

## ★主結果1 — 「追加 supervised の回収」説は棄却された

**r=1.0 は WS-T とほぼ同じ −7.6**(score 13.00% vs WS-T 13.50%)。r=1.0 は r=0.50 の **2倍の supervised update**(12,800 vs 6,400)を受けているので、「+79 が supervised 用量の効果」なら r=1.0 は +79 以上になるはずだった。**逆に 87 Elo 低い**。

∴ **用量反応は単調でなく r=0.50 に内点最適を持つ**(`INTERIOR_OPTIMUM_AT_050`):

| r | 0 | 0.25 | 0.50 | 1.00 |
|---|---:|---:|---:|---:|
| ΔElo vs WS-T | −74.0 | +21.3 | **+79.1** | −7.6 |

純 visit 分布(r=0)でも純 supervised(r=1.0)でもなく、**混合だけが WS-T を上回る向きに出た**。=094 の +79 は「自己対局を捨てた分の supervised 回収」では説明できない。

## 判定 = **`NO_ARM_ABOVE_WST_SELFPLAY_UNRESOLVED`**

- **どの arm も WS-T を有意には超えない**(r=0.50 の +79.1 の CI 下端 −11.1 が惜しくも 0 を割る)。
- **自己対局の限界寄与は未解決**(+37.8 [−27.0, +103.5])。
- **ただし本タスクの主目的は達成**: 「+79 は追加 supervised の回収」という最有力の代替説明を**棄却**した(r=1.0 = −7.6 ≪ +79.1、supervised 用量は2倍)。残る説明は「**混合そのものが効いている**(自己対局が錨と共存する時だけ正に働く)」だが、それは本標本では統計的に確立していない。
- 3分岐の事前予想に対する結果: 分岐1(自己対局無寄与)=**棄却**、分岐2(共存時のみ正)=**点推定は支持・CI は未確立**、分岐3(全フラット)=WS-T 超えが無いという意味では該当。

## 過程で判明した計測系の欠陥(2件、いずれも修正/記録済)

1. **回帰ゲートの許容誤差が実測ノイズ床を下回っていた**。初回起動は `REGRESSION_FAIL_ABORTED` で 22 分で中断。帰属を実測で切り分けた結果 **改修は無罪**:改修コードの複製走が 094 公表値を**全7指標 bit-exact に再現**(原コード の今日の走行の方がむしろ `anchor_top1` で 0.0002 ずれた)。初回ゲート走でも r=0.50 は全7指標 bit-identical。落ちた1走は**自己対局スキャン(512step×32sim)の間欠的非決定性**(Δ`visit_ce` 0.0079, episodes 412 vs 414 — 同一入力のはずの両arm が食い違った)。**修正は許容誤差の緩和でなく再試行**(7指標の bit-exact 一致は実バグ下では起こらない ⇒「1回でも一致すれば PASS、再現した不一致のみ有罪」)。再走で `r025 attempt1 0.00790 → attempt2 0.00010` / `r050 attempt1 0.00000` = **PASS**。
2. **等価性判定の基準が厳しすぎた(未解決・当該最適化は未使用)**。`EQUIV_FAIL` だが実測は `max_abs_force_vs_skip = 1.511e-02` に対し**複製走同士のノイズ床 `max_abs_skip_vs_skip2 = 1.424e-02`**、`replicate_bitwise_identical=False`。両者は同オーダーで、差は 6%。**同一分布からの2つの draw に厳密不等号(force ≤ noise)を課したので約50%で落ちる基準だった**(1と同じ設計ミス)。事前登録したフォールバックが働き、**r=1.0 は生成ON の正準経路で本走**(+3.7h)。∴ **本タスクの科学的結論は影響を受けない**(r=1.0 は r=0.25/0.50 と完全同一 code path を実行した)。**自己対局スキップ最適化は未検証のまま・未使用**。

## 申し送り
- **確定**: (a) 同じ 2M を追加で回す段は枯れている(過学習が始まる、外部は動かない)。(b) 094 の +79 は supervised 用量では説明できない。(c) 用量反応は r=0.50 に内点最適を持つ。
- **未解決の一点**: 混合の優位(Δ_selfplay)。決着には **2,430局/系列(~11h)**。**やるなら block を増やすだけでよく、学習は不要**(ckpt は保存済)。ただし +37.8 が真値なら 6 倍の標本でようやく有意=**費用対効果は要判断**。
- **より安い代替**: (i) r=0.75 を足して内点最適の形を確かめる(学習25分+対局2ブロック)。(ii) block3 が再現しなかった原因(セッション効果 vs 純ノイズ)を、同一セッション内で block を増やして切り分ける。
- **★スコープの限界(重要)**: `config.seed` は自己対局のみを駆動するため **各 arm の学習は1走のみ**。paired CI は**対局ノイズだけ**を覆い、**学習シード分散を含まない**。∴ 主張は「**この** r=0.50 ネットと **この** r=1.0 ネットの間の限界効果」に限定される。「自己対局は一般に X Elo 寄与する」と言うには別シードの r=0.50 再走(+4.1h)が要る。
- **計測系の宿題**: (a) 等価性判定を「ノイズ床に対する比」に直す(現行は厳密不等号=偽陽性50%)。(b) `BLOCK_HETEROGENEITY` フラグ未実装 — ブロック別 Δ の CI 比較を入れる(今回 block2 +80.9 / block3 −3.4 の乖離を機械検出できなかった)。
