# Task 032: 既存 model_wd1e-4 を nnue-diag で診断(度合い圧縮の確認・最安実験)

## 結論

- 既存の `model_wd1e-4`(正則化弱め、Task 017)を `nnue_f32.bin` に export して `nnue-diag`(Task 031)にかけ、
  `model_wd1e-3` の Task 031 結果と同一条件・同一局面で並べた。**学習はしていない。測っただけ。**
- **wd1e-4 は度合い圧縮を解かない。** 絶対値は全体的に大きくなるが、肝心の decisive 局面(飛車得/飛車損)では
  技巧2に対して依然 ~0.05〜0.2 倍にとどまり、むしろ near-equal を膨らませる分、**「優勢/互角を区別する分解能」は悪化**した。
- 符号は両モデルとも代表局面で 6/6 一致(向きは正しい)。だが**「少し良い」と「完全に勝ち」を区別できない核心の欠陥は wd1e-4 でも残る**。
- → **正則化ノブだけでは直らない。次段②(目標スケール見直し=`sigmoid(eval/600)` 飽和の解消・decisive 局面の重み付け)が必要**、という根拠が得られた。

## 手順
- export: `python -m trainer.export_nnue ~/binbo-shogi-data/models/model_wd1e-4 --weights nnue_best.pt --out nnue_f32.bin`
  (wd1e-3 と同じく best チェックポイントを使用。45,249,496 bytes、scale_cp=600)。
- 測定: `nnue-diag <wd1e-4/nnue_f32.bin> <gikou> 20260623 2000 8 6 60`(Task 031 と同一引数)。
- 技巧2 d1/d8 は決定的なので、同一局面では Task 031 と同じ score を返す(代表局面の物差しは共通)。

## B-1. 代表局面の比較(同一局面・apples-to-apples)

生徒は「静的 / 探索」、技巧2は d8。符号はすべて一致(両モデル 6/6)。

| 局面 | wd1e-3 静/探索 | wd1e-4 静/探索 | 技巧2 d8 | 所見 |
|---|---:|---:|---:|---|
| 序盤(平手初期) | 143 / 47 | 318 / 282 | 151 | wd1e-4 は near-equal を**過大**(282 > 技巧2 151) |
| 序盤(▲7六▲3四) | 160 / 122 | 389 / 165 | 72 | 同上(165 > 72) |
| 中盤(戦術) | 1612 / 1038 | 1542 / 1374 | 1556 | wd1e-4 が技巧2に近い(0.67→0.88) |
| 終盤(物差し) | 113 / mate3 | 466 / mate3 | mate3 | 詰みは両者一致(探索が掴む) |
| 先手 飛車得 | 446 / 603 | 802 / 556 | **2635** | 探索値はほぼ不変(603→556)。**依然 ~0.2 倍** |
| 先手 飛車損 | −117 / −129 | **−1** / −157 | **−2405** | wd1e-4 静的は飛車損を **±0** と誤読。探索 ~0.06 倍 |

### 度合いの「分解能」= decisive ÷ marginal(これが核心)

|飛車得 探索| ÷ |序盤 探索| で「優勢局面を平凡な序盤からどれだけ引き離せるか」を見る:

| | 飛車得/平手初期 | 飛車得/▲7六▲3四 |
|---|---:|---:|
| 技巧2 d8 | 2635/151 = **17.5×** | 2635/72 = **36.6×** |
| wd1e-3 探索 | 603/47 = 12.8× | 603/122 = 4.9× |
| wd1e-4 探索 | 556/282 = **2.0×** | 556/165 = **3.4×** |

- wd1e-4 は decisive 局面(飛車得 556)をほとんど伸ばさないまま、平凡な序盤(165〜282)を膨らませた → **分解能はむしろ低下**。
- decisive 局面の対技巧2比は両モデルとも約 0.05〜0.2 で**変わらない**。圧縮の本体(飛車得/損を大きく見られない)は未解決。

## B-2. 実戦(参考、1局・別ライン)

wd1e-4 で seed 20260623 の同一出だしを指すと、生徒の着手が変わり別の進行になった(直接比較は B-1 が本筋)。

- 序盤(ply6〜16)は wd1e-4 が技巧2と符号一致(探索 +176〜+244 / 技巧2 +288〜+318)= wd1e-3 の同区間(−30/−1/+20=符号ノイズ)より良い。
- だが中盤 ply18〜36 で生徒が +100〜+436 と「有利」を主張し続ける裏で技巧2は劣勢判定(符号 NO が連続)。**near-equal を過大評価する分、傾きかけの局面で「勝っている」と誤認**しやすい。
- 結果は **ply56 で student_mated(負け)**。符号一致 **14/25**(wd1e-3 は別局で 19/27)、生徒最善=技巧2d8最善 **11/25**。
- ※ 1局の標本なので強さの判定ではない(棋力測定は Task 029/030 の役割)。傾向の確認にとどめる。

## 所見(次段の判断材料)
- **wd1e-4 は「圧縮を解く」改善ではない。** 出力が全体に大きくなるだけで、decisive 局面の評価は技巧2の ~1/5〜1/20 のまま。
  near-equal を膨らませる分、優勢/互角の**分解能はむしろ落ちる**。実戦の符号一致もこの 1 局では悪化。
- これは「正則化の強さ」ではなく**目標(objective)の問題**を裏付ける: `sigmoid(eval/600)` は勝勢で飽和し勾配が消えるため、
  wd を変えてもモデルは decisive 局面で大きな logit を出すよう押されない。両モデル共通で decisive が伸びないのは整合的。
- 補足: wd1e-3 は best val 0.6182、wd1e-4 は 0.6279(やや劣る)。val ロスでも wd1e-3 が上で、wd1e-4 は「大きいが雑」。
- **→ 次は②目標スケール見直し**(cp 直接回帰 or 勝率変換の温度/スケール、decisive 局面の重み付け)に進む。`docs/BACKLOG.md`「評価の再学習・キャリブレーション」。
