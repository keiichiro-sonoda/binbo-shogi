# Task 024: 反復深化(IDDFS, 時間打ち切りなし・最大深さ固定)

## 結論

- αβ+TT に **反復深化(iterative deepening, 深さ1→D)** を入れた(`src/search.rs::search_iddfs`)。
  TT は **think の最初に1回だけクリアし、深さ間で持ち越す**。詰みを見つけたら break。時間打ち切りなし。
- **正しさ**: 固定深さ D+TT(Task 023)と **最善手・評価値が完全一致**(全ベンチ局面・全深さ、MISMATCH なし)。
- **効果(正直に)**: ムーブオーダリング未実装の反復深化「単体」は、非戦術局面では**小さなオーバーヘッド**
  (深いほど相対的に縮小: 中盤・深さ5で +5.3% ノード / +4.0% 時間)。一方、**詰みが早く見つかる局面では
  mate-break で大幅減**(終盤・深さ5で −97.1%)。
- **品質**: 反復深化(深さ3)対 固定深さ(深さ3)の自己対戦は **19-19(互角、負け越しなし)**。
  対 Random は 30戦30勝。
- これは想定どおりの基準作り。**反復深化の真価は次段のムーブオーダリング(浅い最善手を深い探索の
  手順先頭に)で出る**。今回はその相乗効果を分離して見るための一段。

## 設計(`src/search.rs`)

- `root_search`(内部): 1 回分のルート探索。**TT をクリアしない**・`nodes` に加算する。反復深化が
  深さごとに呼び、TT を深さ間で持ち越せるようにした。
- `search_root`(固定深さ, Task 023 互換): 冒頭で TT クリア → `root_search(D)`。
- `search_iddfs`(新規): 冒頭で TT を**1回だけ**クリア → `for d in 1..=D { root_search(d) }`、
  最深の結果を返す。`best_move` が無い(resign)か、score が詰み圏(`|score| >= MATE_THRESHOLD`)なら break。
- TT のクリアは think 単位(深さごとにはしない)= 反復深化の土台。深さ d の score/bound が深さ d+1 で probe される。
  - 注: best_move による**順序付けはまだしない**(次段)。今回は score/bound の depth 流用が深さ間でどう効くかを見る段。
- `NnueEngine` は `search_iddfs` を使用(`use_iddfs` フラグ、既定 true。比較用に false=固定深さも選べる)。

## 効果測定(`nnue-bench`: 固定深さ D+TT → 反復深化 1→D+TT, 同一局面・深さ)

`dnodes`/`dtime` は反復深化の対固定深さ増減(+ は反復深化が多い/遅い)。全行で best/score が両者一致。

- **非戦術局面**: 反復深化は d1..D-1 を余分に読む分わずかに増える。ただし最深イテレーションがノードの大半を

## 正しさ・品質の確認

- **最善手・評価値一致**: 上表のとおり、固定深さ D と反復深化 1→D で best move・score が完全一致(全局面・全深さ)。
- **自己対戦(`nnue-idmatch`, 反復深化(D) 対 固定深さ(D), 同深さ, 乱数オープニング)**:
  深さ3で **iddfs 19 / fixed 19 / 引分 2 = 互角(19-19)**。最終深さが同じで指し手も同一なので対称的に互角、
  **負け越しゼロ**(DoD: 負け越さない を満たす)。
- **詰み発見**: ベンチ終盤で score=29997(MATE-3)を正しく出し、mate-break で深掘りを止める。
- **回帰**: 反復深化エンジン(深さ3)対 Random = 30戦30勝。`cargo test` 16/16、perft 1〜5 完全一致、
  `selfplay` 完走、option 無指定 USI は Random フォールバック、ビルド警告なし。

## 所見と次段の見込み

- 反復深化「単体」(ムーブオーダリングなし)は、想定どおり**非戦術局面では小さなオーバーヘッド**。
  深さが増すほど最深イテレーションが支配的になり、オーバーヘッド比率は下がる(中盤・深さ5で +4%)。
- **次段=ムーブオーダリング**で TT 保存済みの best_move(浅いイテレーションで得た最善手)を深い探索の
  手順先頭に置けば、αβ枝刈りが激増し、このオーバーヘッドを上回る大幅高速化が見込まれる。今回の表
  (固定深さ vs 反復深化)が、その相乗効果を分離して測る基準になる。
- 副産物として、mate-break が戦術局面で確実に効いている(終盤 −97%)。
