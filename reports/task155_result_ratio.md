## 読み
- Task 154 と合わせると, 割合と強さの関係はおおよそ次のとおり (3 割との差, 評価値だけの版は Task 154 の値から差し引きした概算)。
  - 0 割 (評価値だけ): 約 −11.5
  - 1.5 割: +4.9 (区別できない)
  - 3 割: 0 (採用中)
  - 5 割: −21.7 (はっきり弱い)
- 勝敗は少し混ぜると効くが, 混ぜすぎると悪くなる。良いところは 1.5〜3 割のあたりで, その中の差は今の判定では見分けられない。
- 2 周目も 3 割のまま進めるのが妥当。
