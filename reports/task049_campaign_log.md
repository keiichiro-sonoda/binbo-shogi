## Round 1 実装メモ(src/search.rs)

新規(全て `Opts` フラグ + `full()` で ON、bench で個別 OFF 可):
- **静止探索 `quiescence`**: 葉(depth0)で取り合い延長(王手中は全回避手、それ以外は取る手のみ)+ stand-pat。
  ply cap 32 + 時間で停止。詰みは正しく返す(`score mate 3` 確認済み)。
- **王手延長 `use_check_ext`**: 王手中は +1 深さ(ply<48 でループ防止)。pv テーブルを ply に応じ動的拡張(バグ修正済み)。
- **killer `use_killers`**: ply ごとに beta-cutoff した静かな手2つを優先。
- **history `use_history`**: 静かな手の cutoff 累積(`from*128+to` 配列, ORDER_KILLER 未満にクランプ)。
- 検証: cargo test 18/18, perft 1〜5 一致, 詰み発見 OK(mate3)。
- 注: nnue-bench の MISMATCH は静止探索が探索値を変える=正常(順序のみでない)。

### WDL(本物の対局結果)実装 — Lv3/Lv4 用の評価レバー

- `src/teacher/gen.rs`: game 単位バッファ + 結果 back-fill(MateScore 符号 / resign / win / max_ply で勝敗判定)。
  小規模生成で gameResult = Draw 402 / BlackWin 2630 / WhiteWin 1968 = **92% decisive**(本物の勝敗)を確認。
- `trainer/prepare_data.py`: `*_wdl.npy`(side-to-move +1/0/-1)をキャッシュ。`train_nnue.py`: `--wdl-weight α`
  で `loss=(1-α)cp + α·BCE(sigmoid(forward), 勝敗)`。モデル構造不変=Rust 推論に影響なし。
- run_wdl_2m(depth8, WDL付)を生成中 → shared+WDL を学習し Lv3/Lv4 で評価(cp-only と ablation)。

### WDL ablation 結果: 効かない(打ち止め)

| モデル(2M, canonical-shared) | Lv3 | Lv4 |
|---|---|---|
| cp-only(wdl_weight=0) | 6.2%(1-22-1) | 0.0%(0-24) |
| **WDL α=0.5** | **6.2%(1-22-1)** | **0.0%(0-24)** |

- **WDL は cp-only と完全同一 = 棋力を改善しない**(評価変更は棋力を動かさないという過去パターン通り)。
- 2M モデルは 8M-LMR(Lv3 25%/Lv4 8.3%)より遥かに弱い = **データ量は効くが WDL は無効**。8M WDL へのスケールは無駄。
- 結論: **評価レバー(WDL)は打ち止め**。Lv3/Lv4 の上積みは**探索**(実証済みの効くレバー)で攻める。
  - Lv4 は LMR で不変だったが、より深い探索(積極 LMR / aspiration)で動くか再確認する。

### WDL インフラの価値(無駄ではない)

WDL は棋力を動かさなかったが、`gen.rs` の game 単位バッファ + 本物の対局結果記録は再利用可能な資産
(将来 AlphaZero 系の自己対戦学習や方策蒸留で必要)。`--wdl-weight` も残す(既定0=無効)。

### 積極 LMR(深い reduction)— Lv3 を上積み(採用)

積極 LMR(reduction を late move/深さで 1→3 に増やす)を現行 LMR と paired 比較(3 seed × 24局 = 72局/レベル):

| レベル | 積極 LMR | 現行 LMR | 差 |
|---|---|---|---|
| Lv2 | 41.0% | 39.6% | +1.4 |
| **Lv3** | **25.0%** | **16.7%** | **+8.3** ✅ |
| Lv4 | 9.0% | 6.9% | +2.1 |

- nnue-bench depth8 で **95%削減・28×速**(1秒で深さ ~10-11)。**積極 LMR が Lv3 を明確に上積み(+8.3pp)** → 採用。
- **Lv4 は ~9% で天井(評価律速)**。深い探索でも Gikou depth4 の KPP 評価に届かない。Lv3 も 25% で parity(45%)に遠い。
- **結論(Lv3/Lv4)**: 探索でできる上積みはここまで(LMR で Lv3 17→25, Lv4 微増)。**Lv3/Lv4 の本丸は評価品質**だが、
  WDL・容量・正準化はいずれも棋力を動かさず(本作戦/過去タスクで確認)、KP 表現の限界。1秒/手・KP eval では
  Lv3/Lv4 互角は到達困難。**Lv1/Lv2 は達成**(探索が効いた)。Lv3+ は評価の表現力(KPP 等の richer 化)が次の本丸。
