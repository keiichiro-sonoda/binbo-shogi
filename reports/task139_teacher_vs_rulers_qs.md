# Task 139 — 静止局面で, 教師と binbo は物差しより玉の混み合いを楽観するか (診断, 学習なし)

日付: 2026-10-18 夜。コード: `experiments/alphazero/t139_teacher_vs_rulers_qs.py` (置き換え) + `t133_king_safety_probe.py` (evaluate / label / analyze)。
結果: `~/binbo-shogi-data/work/task139/` (`positions_qs.tsv`, `labels.tsv`, `analyze.txt`)。

## 方法
Task 133 の実戦の 2,985 局面 (floodgate レーティング 3,800 以上どうし 176 局 + binbo の自己対局 40 局) を, やねうら王 `qsearch_psv`
(探索の評価関数は採用 eval) で静止局面に置き換えた (38.0% が変わり, 置き換え後に王手 0)。同じ局面で tanuki- / AobaNNUE / binbo を 20 万ノード・1 スレッド,
教師 WS-T を S=8 と生の value で評価。Task 133 と同じ回帰 (目的 = 教師または binbo, 説明 = 物差し 2 本 + 玉の周りの特徴, 対局単位のブートストラップ)。

## 結果 (全 2,742 局面, |tanuki| ≤ 1500)
| 目的 | 物差しとの相関 (tanuki) | stm_att2 (自玉の近くの敵) | opp_att2 (相手玉の近くの自駒) |
|---|---|---|---|
| 教師 S=8 | 0.47 | **−42** [−71, −15] | **+44** [+22, +65] |
| 教師 生の value | 0.49 | −30 [−63, +1] | +38 [+16, +63] |
| binbo (20 万ノード) | 0.75 | +11 [−9, +29] | +7 [−11, +23] |
| (参考) Task 133: binbo, 置き換え前の局面 | 0.73 | +20 [+3, +37] | +27 [+12, +42] |

## 読み
- **静止局面では, binbo の玉の混み合いへの楽観は小さく, 0 と区別できない** (+11 / +7, 幅 ±20)。Task 133 の +20 / +27 は, 取り合いの途中の局面を含めたときの値。
- 教師は静止局面でも, 攻めを物差しより楽観し (+44), 自玉の危険は物差しより重く見る (−42)。それでも生徒 (binbo) にその偏りはほとんど出ていない。探索の分か, 学習で平均されたためかは分けていない。
- 目立つのは**教師と物差しの相関の低さ** (0.47。binbo は 0.75)。教師のラベルは局面ごとのばらつきが大きく, 生徒はそれを平均して教師より物差しに近づいている。
- まとめ: 「玉の危険」を狙った手直し (特徴の追加, ラベルの付け直し, 損失の工夫) から得られるものは小さそう。伸ばすなら, ラベル全体の質 (教師の局面ごとのばらつき) や, データ量の方。
