## 判定の含意
- **勝敗の混合は、物差しで見るとほぼ 0**(新しい対局で +1.0、半幅 ±29)。Task 111・112 の「正の方向」は、主に直接対局と物差し 400 局のばらつきだったと読むのが妥当。少なくとも +30 を超える効果はない。
- **C の物差しでの上積み(+19)は、ほぼ学習率の仕上げの分(対照 − 採用 eval = +18)**。旧+新の合算では C − 採用 eval = +25 [+2.8, +47.9] と 0 を外れるが、これは記述(既に見た対局を含む)。仕上げ・混合それぞれの効果は小さく、合わせて +20 前後。
- **直接対局は、物差しより大きく出ることがある**: C vs 採用 eval は直接 +68 に対し物差し +19。食い違いは Task 104(直接 +134 / 物差し +56)、Task 110(+37 / +16)、Task 112(+38 / +21)でも出ているが、Task 107(+112 / +98)と Task 109(+43 / +47)では出ていない。候補を採用 eval の重みから学習し始めたかどうか(「親子」かどうか)とは対応しない(Task 109 は親子でも一致、Task 104 は親子でなくても食い違い。10/6 訂正)。食い違うときは常に直接対局の方が大きい。原因(似た評価関数どうしの相性など)は未特定。**判定は外部の物差しを主にすべき**。
- 採用 eval は据え置き(事前登録の決定表どおり)。

- 「工夫で伸ばす」方針の ①(学習率の仕上げ)・②(勝敗の混合)は、どちらも +20 前後以下と分かった。次は ③(局面選びの工夫)。Task 106(戦術局面の除外)は物差しでも +48 と確かな効果があった系統。
