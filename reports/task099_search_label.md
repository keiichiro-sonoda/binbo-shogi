# Task 099 — 探索裏付き value ラベル: (a')経路も閉じた(ループ利得は探索を通しても value の数字に翻訳されない)

**目的**: 098 で「**生の value ヘッドには新情報が載らない**」が確定した(共有幹で value は 59.2cp 動き圧縮も起きなかったが、その value を教師にした NNUE 学生は WS-T 学生と区別できず −0.87 [−23.9,+22.2]。ラベル素性も std 1502/1500・corr_gikou 0.958/0.957・|Δ|median 201/202 と実質同一=**WS-T のノイズ殻の内側**)。一方ループの +26〜+27 は**方策×探索**に実在する(097 でレシピ水準の再現確定)。残る未踏の運搬路は「**探索を通した後の root value**」のみ。全量 2M rescore に投資する前にサブサンプルで生死判定した。**学習なし・対局なし・ラベル統計のみ。** 実測 2026-08-15〜16、`RUN_META dirty=0 exp_dirty=0`、実走 19:24〜00:46(**5.4h, rc=0**)。事前登録済み(実行前・ローカル commit)。

## ★この比較が構造的にクリーンな理由
| | ラベラー | 分離するもの |
|---|---|---|
| ① | WS-T 生 value | 殻の中心 |
| ①' | 097 run2 生 value | **帰無対照** |
| ② | WS-T + 探索(root value, sims S) | 探索単独の寄与 |
| ③ | 097 run2 + 探索(同 S) | 探索 + ループ利得の寄与 |

**097 run2 は frozen-value ループの産物なので value 塔が WS-T と bit-identical**。実測: 帰無対照(128局面)で `max_abs(raw_wst − raw_run2) = 0.000e+00`。**全2,882局面では 166局面(5.8%)に差があるが最大 0.339cp・平均 0.0016cp・中央値 0.0000cp** で、091 が記録した「同一重みでもグラフ間で最大±1cp の丸め差」の範囲内(① は WS-T の `base_forward`、①' は 097run2 の `FrozenValuePolicyForward` = 別々に jit された別グラフ)。**`|cp−gold|` の median は 219.2715 で両者完全一致**。∴ 重みの同一性は確認され、残差は XLA グラフ間丸めであって実質的な差ではない。∴
- **③ − ② は「同一の value ヘッドを、外部 +26 Elo 強い policy で導いた探索」の差**。value 品質の交絡が構造的に存在しない。
- 098 が「value ヘッドに新情報なし」を示したのに対し、099 は「**policy が探索経由で value の数字に情報を注入するか**」を余計な交絡なしに問えた。

## ★結論を、バイアスを受けるものと受けないものに分ける

### (A) バイアスを受けない結論 — **ループ利得は翻訳されない**(本タスクの本題)
② と ③ は **value ヘッドが同一**で、**gikou からの距離も同一**:

| | cp std | corr_gikou | \|Δcp\| vs gikou |
|---|---:|---:|---:|
| ② WS-T+探索 | 1447.8 | 0.952 | **242.653** |
| ③ 097run2+探索 | 1446.7 | 0.952 | **242.672** |

小数2桁まで一致。∴ **gold の錨バイアスは ③−② で完全に相殺する**。その上で:
- **d32 = +2.70 [−3.66, +7.79]** = ③ は ② より gold に近くない
- ②③間の直接距離は **median 16.6cp、corr 0.998**
- **sims=32/128/512 のいずれでも d32 の CI は 0 を含む**(+2.70 / +1.73 / −0.76)

> **外部で +26〜+27 Elo 強い policy を積んでも、探索が到達する value の数字はほぼ同じ(16.6cp、corr 0.998)であり、その差は gold への近さを改善しない。**

これが (a') 経路への答えであり、**汚染・錨バイアスのどちらも受けない**。

### (B) バイアスを受ける結論 — 「探索が悪化させた」は額面どおり読めない
探索は生値を **gikou 多様体から引き離す**(`corr_gikou` 0.958→0.952、`cp_std` 1503→1447、`|Δ|vs gikou` 202→243)。gold は **champion NNUE(gikou@d8 蒸留物)の d16 探索**なので、gikou 関数から離れた分は**機械的に罰せられる**。∴ d21/d31 の正値は「探索が劣化させた」証拠として額面どおりには読めない — **事前登録で懸念した錨バイアスがまさに効いている領域**である。

- **だが d32 は全 sims で 0 のまま**。探索を16倍深くしても、**ループ利得は value の数字に翻訳されない**。この結論は探索深さに対して頑健。

## 判定の含意
- **(a') 経路は閉じた**: ループの policy 利得は、探索を通しても value の数字に翻訳されない(d32 ≈ 0、全 sims、バイアスフリー)。
- 探索そのものは value を大きく動かす(188.7cp)が、**動いた方向が良いかは本タスクの計測器では判定できない**(gold が gikou に錨付いているため)。「探索ラベルは gikou 由来の gold より良い可能性」を否定も肯定もしていない。
- 091(教師0)→093(外部悪化)→094(悪化停止)→095(supervised枯渇)→096(混合+28.65)→097(再現)→098(生value は運ばれない)→**099(探索裏付き value も運ばれない)**。**ループの外部利得は実在し再現するが、既知の運搬路は方策(092-0 bridge null)・生value(098)・探索裏付きvalue(099)の全てで閉じている。**

## 申し送り
### (a) 探索ラベルをなお追うなら — 計測器を変えるしかない
本タスクが判定できなかったのは「探索が gikou から離れた方向が良いか」。gold(gikou 蒸留物の深探索)では原理的に測れない。次の一手は**ラベル統計でなく学生試験**:
- **ミニ学生試験**: ② のラベルで NNUE 学生を学習し、① ラベル学生と対決(084方式)。2M 全量 rescore は **S=32 で実測 5.65h**(bench 実測 98/s から)、学生学習2本 ~26分、800局 ~2.5h ⇒ **計 ~8.7h**。**これは「探索ラベルが gikou 由来 gold より良いか」を gold を介さず直接測る唯一の道**。
- ただし ③ でなく **② で足りる**(d32≈0 = ループ利得は寄与しない)。∴ これは「AZ探索ラベル一般」の問いであってループ路線の問いではない。**085 の 2M→32M 反転**ゆえ 2M 勝ちは 32M 確認の資格まで。

### (b) ループ路線を閉じるなら
- **確定**: 単機ループの外部利得(+26〜+27、097 で再現)は実在するが、**方策・生value・探索裏付きvalue の3経路すべてで製品 NNUE へ運べない**。
- 資源復帰先は BACKLOG の既知正方向(32M→64M 蒸留 ~5.6h生成/SPRT vs `task064_32m_lr1e-5`、小/中データの AZ 平滑化ハイブリッド)。

### 計測系の宿題
- **`m2_usi.new_state` に符号バグがある**(`position sfen ... w ...` で `current_player=0` のまま)。本タスクでは対局系の成果物-of-record を動かさないため触っていない。**対局は全て startpos+moves 経由なので現状の測定は無傷**だが、将来 sfen 直接指定を使うなら修正が要る。
- `SESSION_RATE_SKEW` の帳簿式を千日手系込みへ一般化(097 申し送り、未着手)。
