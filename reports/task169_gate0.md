# Task 169: GPU 案の関門 0 = 合格 (昨夜の小さな得は新しい局面でも再現した)

日付: 2026-10-23 (10:27〜11:00)。スクリプト `experiments/alphazero/t169_gate0.sh` (事前登録コミットあり)。

## 何をしたか
- 新しい局面 1,536 個 (1 周目の自己対局の別々の対局から, seed 20271690。昨夜の 256 個は 2 周目の対局から取ったので重ならない)。
- 条件は昨夜 (Task 167) と同じ: 採用 eval `task154_R_result30`, N = 10 万ノード, 一様 1.6N, 重点 4N, 参照 200 万 / 400 万ノード, 旧 WS-T の方策 (GPU)。
- 規則: 方策の 1 位と N の探索の手が一致したら N で止める。一致しなければ, 不一致の局面の一部に 4N, 残りに 1.6N を配る。平均は一様と同じ 1.6N。
- 合格の線 (事前に固定): 実装できる版 (N の後に置換表を残して 3N 足す) の削減の 95% CI 下限 > 0。

## 結果 (安定・詰みなしの 1,022 局面, 一様の平均損失 37.3cp)

| 規則 | 一様に対する損失の削減 | 95% CI |
|---|---|---|
| **方策と一致したら止める (実装できる版)** | **+4.6cp** | **[+0.7, +9.8]** |
| 同 (冷たい 4N の版) | +4.2cp | [+0.3, +9.5] |
| 同, 寄与の大きい 2 局面を除く (実装できる版) | +3.5cp | [+1.1, +6.2] |
| 方策の確率 0.3 以上で一致したときだけ止める (実装できる版) | +2.6cp | [+0.0, +5.2] |
| 比較: 探索の数値だけの規則 (実装できる版) | +0.5cp | [−5.8, +6.9] |
| 比較: 探索の数値だけの規則 (冷たい 4N, MultiPV 2 の費用を数えない) | +6.1cp | [−0.6, +13.3] |
| 比較: 答えを知った配分 (上限) | +25.3〜28.5cp | |

内訳 (実装できる版): 一致で止めた得 +1.2cp, 不一致に時間を足した得 +3.4cp。昨夜と違い, 主に「不一致の局面に時間を足す」側から来ている。

**合格**。寄与の大きい 2 局面を除いても下限は 0 より上で, 少数の局面頼みではない。

## 読み
- GPU の方策と探索が食い違う局面は, 追加で読む価値が高い。この信号は実装できる形で, 探索の数値だけの規則 (実装できる版 +0.5) より良い。
- ただし大きさは小さい: 上限 (約 25〜28cp) の 2 割弱。冷たい 4N で MultiPV の費用を数えない探索だけの規則 (+6.1, 有意でない) とは区別できない。
- これは独立した局面どうしのノードの配分で, 対局中の時間管理ではない。cp を Elo に換算しない。
- 次は関門 1: 「一致か不一致か」だけでなく, 方策の確率や探索の数値も使う小さな予測器を学習し, 別の局面で 4cp 以上減らし, 探索の数値だけの予測器を上回るか。その後, 関門 2 で本番の時計の対局。
