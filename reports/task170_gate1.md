# Task 170: GPU 案の関門 1 = 不合格 (学習した予測器は, 単純な一致の規則も探索の数値だけの予測器も, はっきりとは上回らなかった)

日付: 2026-10-23。スクリプト `experiments/alphazero/t170_gate1.py` (事前登録コミットあり)。新しい探索はしていない。

## 何をしたか
- データ: Task 169 (1 周目の対局, 1,022 局面) と Task 167 (2 周目の対局, 162 局面) の安定・詰みなしの局面, 計 1,184 (すべて別々の対局)。
- 予測の対象: N (10 万ノード) の後に置換表を残して 3N 足したときの損失の減り (cp)。
- 配り方: 全局面に N。予測の上位 2 割に +3N (平均 1.6N, 一様と同じ)。
- 予測器 (調整なし, リッジ回帰 λ = 10):
  - S (探索の数値だけ): 深さ, 読み筋の変化の回数, N の評価値の大きさ, 最後の 4 回の反復での評価値の揺れ, 合法手の数, 手数。
  - G (S + GPU の方策): 方策の 1 位と N の手の一致, 1 位の確率, N の手の確率, 上位 8 手のエントロピー, 方策での N の手の順位。
- 対局単位の 5 分割の交差検証。対局単位のブートストラップ 2,000 回。
- 合格の線 (事前に固定): G の削減が 4cp 以上で CI 下限 > 0, かつ G − S の CI 下限 > 0。

## 結果 (一様の平均損失 36.3cp)

| 予測器 | 一様に対する損失の削減 | 95% CI |
|---|---|---|
| S (探索の数値だけ) | +1.9cp | [−5.0, +8.9] |
| G (S + GPU の方策) | +5.0cp | [−0.9, +11.1] |
| G − S | +3.0cp | [−3.3, +9.4] |
| 参考: 答えを知った配分 (実装できる版の上限) | +27.6cp | [+20.4, +36.2] |
| 参考: 関門 0 の単純な一致の規則 (1,022 局面) | +4.6cp | [+0.7, +9.8] |

**不合格** (G の下限が 0 を下回り, S との差も区別できない)。

## 読み
- GPU の方策を足すと点推定は上がる (+1.9 → +5.0) が, 学習した予測器は関門 0 の単純な「一致したら止め, 不一致に足す」規則とほぼ同じで, それを超える情報は取り出せなかった。
- 上限 (+27.6) の 2 割程度にとどまる。局面 1,184 では, 小さな差を見分けるには足りない。
- 事前の決まりどおり, **大会向けの開発はここで打ち切る**。原理の否定ではない (局面が少なく, 方策は 2017 年相当の旧 WS-T, 予測器は線形)。
- 残る使い道: 「GPU の方策と探索が食い違う局面は追加で読む価値が高い」(関門 0, +4.6 [+0.7, +9.8]) は小さいが再現した事実として, 大会後の研究と, アピールの「効く・効かないの記録」に使える。
