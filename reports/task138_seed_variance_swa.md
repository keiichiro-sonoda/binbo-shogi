# Task 138 — 学習 1 回ごとのばらつきと, 重みの平均 (SWA)

日付: 2026-10-18 夜〜19 朝。コード: `experiments/alphazero/t138_seed_swa.py` (事前登録), `t138b_base_noise.py`, `t138c_retrains_conf138.py`。
結果: `~/binbo-shogi-data/logs/task138_results.json` と各 TSV。

## 方法
採用 eval のレシピ (Task 129) を速い経路 (`--fast`) で seed だけ変えて 2 回 (B = 20261019, C = 20261020) 学習し, 各周の重みを保存。
各 seed の best epoch と, 9〜12 周目の重みの平均 (SWA) を標準の物差し (seed 20272001-08) で採用 eval と比べた。
Task 135 (seed は採用 eval と同じ, 足し算の順序だけ違う) を seed A とみなす。
途中で採用 eval 側の偏りが疑われたので, 採用 eval と B・C を新しい seed の組 2 つ (20273501-08 = conf135, 20273601-08 = conf138) でも指した。

## 読み
- **学習し直した 3 本は採用 eval と同じ強さ** (新しい組では B +9, C +1)。学習 1 回ごとのばらつきは, 対局の運の幅より小さく, この本数では見えない。SWA も効かない。採用は task129 のまま。
- **採用 eval は標準の組でたまたま低い成績を引いている** (対 AobaNNUE で他の 2 組より 20〜30 低い)。ノード数固定の対局は同じ結果を繰り返すので, この 1 回の結果を全比較で使い回している。学習し直した 3 本の差の平均は標準の組で +25.4, 新しい組 (conf135) で +7.7 で, その差 約 18 Elo が採用 eval 側の偏り。
- **影響**: これまで標準の組で採用 eval と比べた差 (Task 134 の +12.2 など) は, 約 15〜20 Elo 甘い。「強い」の判定は新しい seed での確認が要る決まりなので誤採用は起きていない (Task 135 / 138C とも確認で落ちた) が, 「差なし」の読みは下にずれる (Task 134 は実際には −5 前後の可能性)。
- **判定方法の提案** (作者が決める): 採用 eval はすでに 3 組 (2,400 局 × 2 anchor) 指してある。候補も 3 組指して 3 組まとめて比べれば, 基準側の運の影響が約 √3 分の 1 になる (候補 1 本あたり 1h → 3h, ただし Task 137 の早めの打ち切りと組み合わせられる)。または, 候補は標準の組のまま, 採用 eval の標準の組の偏り (約 −16 Elo) を報告に併記する。
