# Task 171: 本物の水匠5 と水匠5 の生徒の比較 (手元で対局させるだけ) = 水匠5 が約 +300〜370 上

日付: 2026-10-23。スクリプト `experiments/alphazero/t171_suisho5_local.py`。

## 条件
- 水匠5 の nn.bin: やねうら王の GitHub リリース `suisho5` の `Suisho5.7z` (24.1MB, sha256 `6734e3a3…`, nn.bin sha256 `768068f0…`)。
  リリースにもブログにもライセンスの明記がないため, **手元で対局させるだけ**に使う。学習・物差し・配布物・大会には使わない (作者と合意, 10/23)。
- 枠は候補と同じ: 新しい 3 組 × tanuki- @2 万 / AobaNNUE @1 万, 候補は 10 万ノード。水匠5 はリリースの推奨の FV_SCALE 24 (binbo 系は 16)。
- 水匠5 が一方的に勝つため, 対局の道具が途中で打ち切ったチャンクが 8 個あった (89〜99 局, エラー 0)。そのため対の照合 (delta_sets) は通らず, 得点率から対にしない形で計算した。

## 結果 (物差しに対する得点率と Elo 換算, 95% CI はブートストラップ)

| 評価関数 | 対 tanuki- | 対 AobaNNUE |
|---|---|---|
| 水匠5 本体 | 0.968 (+595 [+557, +638], 2,363 局) | 0.943 (+488 [+460, +520], 2,396 局) |
| 生徒 + 雑巾絞り (S_R2) | 0.817 (+260) | 0.765 (+205) |
| 水匠5 の生徒 | 0.784 (+224) | 0.742 (+184) |
| 今の採用 eval (task154) | 0.747 (+188) | 0.688 (+137) |

差: 水匠5 − 生徒 = +371 / +305, 水匠5 − S_R2 = +335 / +283, 水匠5 − 採用 eval = +407 / +351 (tanuki- / AobaNNUE)。

## 読み
- 同じ形 (HalfKP 256x2-32-32) でも, 教師の水匠5 本体と, binbo の学習器で 6,400 万局面 (全体の 0.8%) を学習した生徒の間には約 300 以上の差がある。
- 水匠5 は物差しに 95% 前後勝つので, この物差しでは Elo の推定が粗い (差は「数百」と読む)。FV_SCALE も 24 と 16 で違う。
- 同じ形のままでも, データの量と学習の規模でまだ大きく伸びる余地がある。
