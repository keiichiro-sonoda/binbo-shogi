# Task 162: 捨てた局面 (静止化で変わった葉) は既存の学習データとどれだけ重なるか

日付: 2026-10-22 (11:18〜11:37)。スクリプト `experiments/alphazero/t162_changed_overlap.py`。

## 何をしたか
- Task 159 (2 周目) の自己対局の棋譜を使い, 静止局面への置き換えを「変わっても捨てない」(`--changed inherit`) でやり直した。
  評価関数・設定は Task 159 と同じ。残していた行は 984.9 万行で, Task 159 の記録と同数。
- 変わった葉 (取り合いを進めた先の局面) 670.6 万個を, HalfKP の 77 特徴の完全一致 (盤面・持ち駒・手番) で照合した。
  - 照合先は Task 159 / Task 154 の学習データと, 変わった葉どうし。
  - 照合には 64 ビットのハッシュを使った (同じハッシュの全列照合はしていない)。

## 読み
- 心配したとおり, 葉の約 4 割は実際の対局で後に現れて既に学習している局面だった。葉どうしの重複も多い。
- それでも重複を除いて **約 318 万個の新しい局面** が残る。学習データ (983 万) の約 3 割にあたる。
- 終局に近いほど新しい割合が高い (7 手以内で 59%)。終盤が薄いという Task 156 の偏りを, 付け直しで実際に埋められる。
- 付け直しの実験 (Task 161 の 4) は, 重複を除いた新しい局面だけを対象にして進める価値がある。
