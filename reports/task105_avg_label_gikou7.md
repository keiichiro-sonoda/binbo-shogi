# Task 105 — 平均ラベル 1:1 は探索ラベルと互角(`PARITY`)、物差しを技巧2@7 に上げても「探索学生 − champion ≈ +57」は再現

一変数 = 教師ラベル。32M 局面それぞれで (clip(技巧2@d8, ±2000) + clip(探索ラベル, ±2000)) / 2 を正解にした学生を、Task 104 と同じコーパス・レシピで学習し、採用中の探索学生と比べた。並行して、採用 eval が 87% 勝って飽和しかけていた技巧2@6 を技巧2@7 に替えた。事前登録済み(preflight の修正)、ドライバ `experiments/alphazero/t105_avg_label.py`、10/4 02:02 → 06:44(`rc=0`)。

## 判定の含意
- **技巧2@d8 ラベルを混ぜても上積みはない**: 1:1 平均は探索ラベル単独と区別できない(−5)。業界のアンサンブル教師の利得は「強い教師同士」を混ぜたときのもので、ここでは一方(技巧2@d8)が他方(探索ラベル)の元になっている(WS-T は技巧2 の蒸留)ため、混ぜても新しい情報が増えないと読める。
- 採用 eval は `task104_student_search` のまま。
- 技巧2@7 の物差しは安定(4,000 局超でエラー 0)で、champion 74%・探索学生 80% と飽和から離れた。
- 留保: 学習 seed n=1。平均の重みは 1:1 のみ(散らばりを揃える版は未試行)。物差しの測定が GPU 学習と並走したため、別時期に測った腕どうしは nodes がずれる(今後は物差しの腕を同じ条件で測る)。
