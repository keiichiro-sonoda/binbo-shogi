# Task 142 — 公開教師データ (nodchip/shogi_suisho5_depth9) を使う

日付: 2026-10-19。コード: `experiments/alphazero/t142_public_suisho5.py` (事前登録)。結果: `~/binbo-shogi-data/logs/task142_results.json`。
データ: Hugging Face `nodchip/shogi_suisho5_depth9` の検証用 `shuffled.bin` (289,626,920 B, sha256 `7590e128…`, **MIT**)。
水匠5 depth 9, 静止探索の PV 末端に置き換え済み, シャッフル済み。7,240,673 局面 (王手 0, 評価値は手番側の cp でやねうら王の目盛り = binbo のラベルと同じ, |cp| ≥ 2000 が 29%)。

## 方法
- 変換: PackedSfenValue → binbo の特徴 (canonical shared 77 列)。抜き出した 2,000 局面で特徴から盤面に戻すと元と一致。
- **B 仕上げ (finetune)**: 採用 eval (task129) の重みから始め, 公開データ 724 万局面だけで 2 周, lr 1e-5, 最後の重み。`--fast`。
- **A 混ぜる (mix)**: 自前 63.95M + 公開 7.24M = 71.19M で Task 129 と同じ学習 (lr 6e-5, 12 周, best epoch)。
- 判定 (2026-10-19 の改定): 3 組の seed (std / conf135 / conf138) をまとめたペアの差。強いなら新しい組 conf142 (20273701-08) で点推定 > 0 を確かめる。

## 結果

- B の学習は 2 周で数分 (724 万局面 × 2)。val loss (自前の WS-T ラベル) は 41,086 → 100,352 と大きく上がるが, ラベルの付け方が違うので強さとは別 (val は自前の教師との近さ)。
- A は val loss も 45,319 に上がり, 強さは区別できないか少し悪い。

## 読み
- **自前の教師で学習した評価関数を, 強いソフトの深い探索 (水匠5 depth 9) のラベルで少しだけ仕上げると, はっきり強くなる** (3 組で +29.5, 確認の組で +47.3。どちらも下限が 0 より上)。対 tanuki- の伸びが大きい。
- 同じデータを自前の 64M に 1 割混ぜて最初から学習しても効かない。量で勝負するより, 最後に質の高いラベルへ寄せる方が効く (tanuki- チームが大会前にたややん氏のデータで仕上げるのと同じ形)。
- Task 139 の「自前の教師 (WS-T S=8) は物差しとの相関が 0.47 と低い」とも合う: ラベルの質が律速だった可能性が高い。
