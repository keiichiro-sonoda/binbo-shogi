# Task 130 — 教師スコアの分布の較正(32M): `CALIB_NEUTRAL`、較正 − 対照 = −21.2 [−44.7, +2.3]

調査(`docs/research_survey_2026-10-12.md` の提案 1)に基づき、WS-T のラベルを、順位を保ったまま技巧2@d8 の評価値の分布へ写した(tanuki- の 2026-09 の手法)。事前登録済み、ドライバ `experiments/alphazero/t130_label_calibration.py`。実行は 10/12 18:56 → 23:26(`rc=0`、失敗なし)。

## 写像

## 学習
- 32M・除外なし・lr 6e-5・Factorizer・12 epoch。違いはラベルだけで、対照は Task 128 の腕 C。
- best epoch は 11、val loss は 57,811。ラベルが違うので、対照の val loss と比べる意味はない。
- 0cp ゲートは GREEN。

## 解釈
- tanuki- では、同じ学習順の比較で +44 だった。当方では効かず、むしろ悪化寄りだった。
- tanuki- で「勝率への換算係数を動かすと −20〜−66」だった結果、および当方の Task 118(FV16 が最良)と合わせると、**評価値の大きさの付き方は、今の WS-T の atanh の尺度で探索とよく噛み合っている**と読める。技巧2 の分布の方が「正しい」わけではない。
- WS-T が手番側を約 100cp 低く見る偏りも、探索の中では害になっていないらしい。手番側の値を持ち上げた較正が悪化寄りだった。
- 留保: 学習 seed は 1 本。CI 上限は +2.3 で、悪化をはっきり示すほどではない。
