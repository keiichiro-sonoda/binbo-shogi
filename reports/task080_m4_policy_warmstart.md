# Task 080 — M4: 方策 warm-start(技巧2 bestMove16)→ 自己対局ループ =「吸引点を超える」検証

**目的**: 079 で確定した「価値のみ warm-start はパリティ吸引点で止まる」に対し、**方策という第二の知識軸**を注入して吸引点が動くかを検証。**3点比較(WS1=価値のみ / WS2=価値+方策 / genN=ループ後)**で「方策温めの効果」と「ループの効果」を分離測定。先行構造= AlphaGo(SL 方策→RL が SL 超え)。実測 2026-07-04〜05、隔離環境(m4_*.py 非コミット)、**リポジトリは文書のみ・Rust 無改変**。

## ステップ0 — データ(m4_distill_data.py)
- m2/m4 同一サンプリング(seed 20260702、train 2M+val 50k=末尾 5 shard 分離)に **方策ターゲット追加**: `bestMove16 →(board.move_from_move16)→ USI →(検証済 m2_moves.usi_to_action)→ Pgx action(int16)`。
- **skip = 0 / 2.05M**(expand 失敗 0・非合法 0・写像失敗 0)= 経路の頑健性を全量で確認。ビルド ~10 分。

## ステップ1 — WS2(価値+方策の同時蒸留)と、方策温め単体の寄与
- 同時教師あり学習(**再学習・M2 と同一条件**: adam lr1e-3 / batch4096 / 4ep / ~5 分): loss = MSE(v, tanh(cp/1200)) + CE(policy, bestmove one-hot)。
- **WS2 = 価値 corr 0.873 / 方策 top-1 34.1%**(best ep3。価値 corr は M2 の 0.900 よりわずかに低い=共有トランクを 2 ヘッドで分け合うトレードオフ、記録)。参考: AlphaGo SL は人間手 57%(net/教師規模が別物)。
- **WS2 vs WS1(方策温め単体の寄与)= 89-0-0 完封(SPRT accept_h1 @89 局)**: score 1.0 → **片側 95% 下界で ≥ +586 elo**。**079 で 400 iter の自己対局 RL が到達できなかった水準を、~5 分の方策蒸留が飛び越えた**(価値の再導出 ≪ 方策知識、という軸の非対称性)。
- 外部アンカー: WS2 vs champion **0-0-200**(≤−730)/ vs gikou@6 **0-1-99**(≈−920)= WS1 と同じ床(内部 +600 の差は外部床の分解能以下)。

## ステップ2 — WS2 からループ(078/079 と同一設定: lr1e-4 / sims32 / 64ch×5L / batch256 / steps512)
- m3_loop に **方策 top-1 監視**を追加(corr と同パスで毎 iter)。一晩 150 iter、median 418s/iter(監視込)、**WARN/RESTART 0 件**。
- **監視推移が 078 と別世界**: 価値 corr **0.72-0.79 帯で安定**(078 は 0.2-0.4 帯まで崩壊)/ **top-1 0.336→0.288**(緩やかな適応ドリフト=方策知識は保持)/ episodes 平均 **1,058/iter**(078 初期 ~630、崩壊期 ~260)=**最初から最後まで濃い決着型の対局**。「無目的対局の谷」は発生せず。

| カーブ(vs WS2, 各40局) | iter10 **+17** → 50 **+53** → 100 **+127**(CI +27..+254)→ 150 **+133**(n=255) | **谷なし・単調上昇** |

## **M4 判定 = PASS —(c) の目標『単機の自己対局 RL が正の elo を生む』を達成**
- **主判定 SPRT accept_h1**: gen150 は WS2 より **+133 elo(CI +92..+177)**有意に強い。**方策注入で吸引点は動いた**=自己対局 RL は(適切な初期化の上で)初期化点を有意に超えられる。
- **066-072(αβ蒸留の自己強化=全否定)との対比が完成**: 同じ「自己対局で強くする」でも、探索を MCTS+方策改善に変え、方策+価値の両軸を warm-start すれば、フル将棋・単機一晩で +133 elo。
- **079 との対比で機構も明瞭**: 価値のみ→教師相当 value の再導出で止まる(吸引点)/ 方策あり→濃い対局が最初から生成され、その勝敗が新しい価値知識を供給し続ける=**自己対局の質が学習信号の質を決める**。
- 留保: +133 は WS2 比の内部尺度。外部アンカー(champion/gikou@6)にはまだ届かない(下記副次)= 絶対棋力の登りはこれから。

## 副次測定(gen150)
- **vs champion(byoyomi 100ms, 200 局)**: **0-4-196(draw 4)= (c) アーク初の非ゼロスコア**。score 0.010 → elo −798(CI −1410..−679)。これまで全系(WS1/WS2/m3 gen150)が 0-0-200 だった champion の床に、初めて引き分けが 4 つ入った。

## 詰まりどころと学び
- WS2 ckpt をループの ckpt_dir に置くと `resume=auto` の glob/連番パースと衝突しうる → **WS2 は別ディレクトリ(m4_ws2/)**に置き init_ckpt で渡す設計に。
- 共有トランクの 2 ヘッド同時蒸留は価値 corr をわずかに下げる(0.900→0.873)が、ループでの保持は圧倒的に良い(方策が対局の質を上げるため)= 単頭の最適化より**系全体**での評価が正しい。
- 3点比較(WS1/WS2/genN)の分離測定が、寄与の切り分け(蒸留 +586 / ループ +133)を可能にした=一変数分離の設計が結論の強さを支えた。

## M5+ への申し送り
- **絶対棋力の登り**: gen150 の外部アンカー到達が次の壁。候補=①ループ延長(カーブは iter150 でまだ上昇中: 100→150 で +6)②net スケールアップ(M1 実測: 128ch×10L でも selfplay 1.4× で済む=env 律速)③sims↑(選択的に)④`max_num_considered_actions`↑。
- 蒸留データ規模(2M)と教師深度(d8)も未探索の軸(champion 系列の資産=32M/d12 基盤が既在)。
- 判定系・ループ・監視(corr+top1)は全て流用可。通算 3,000 局超・非合法手 0。
