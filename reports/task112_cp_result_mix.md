## 判定の含意
- **勝敗を混ぜる効果は、2 回の実験(Task 111・112)で一貫して正の方向**: 直接対局 +16.5 / +37.9、AobaNNUE +47.8 / +47.3、物差しまとめ +30.5 / +20.9。どれか一つでは確定しないが、向きは毎回そろっている。tanuki- だけは 2 回とも 0 付近(+12.9 / −5.4)。
- **物差しの検出力が足りない**: 物差し 2 本 800 局の半幅は約 ±40 Elo で、+20〜30 の効果は見分けられない。今回の型(直接は確定・物差しは未確定)は Task 110 とも同じ。
- C は採用 eval(Task 109)に対しても +37.4 [−0.6, +75.8] と、ほぼ確定の手前。
- 採用 eval は据え置き(事前登録の決定表どおり)。

## 申し送り
- 小さな効果を判定するには、物差しの局数を増やす必要がある(各物差し 1,600 局で半幅 ≈ ±20)。ノード固定の対局は CPU だけで速い(1 局 ≈ 4〜5 秒)ので、採用 eval・Task 110・C の 3 者を新しい seed で物差し 2 本に各 800 局ずつ追加しても ≈1.5h。
