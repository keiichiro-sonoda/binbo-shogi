# Task 036: 左右対称データ拡張で汎化を上げる — train/val の度合いギャップが縮んだ

## 結論

- 左右対称(水平鏡映)データ拡張を**学習側のみ**に入れた(目標=cp 回帰+clamp±5000+MSE, 構造=fd32, 元データ=100万局面、すべて据え置き。
  左右反転の追加だけ)。将棋の駒は全て左右対称なので、鏡映は**値を保つ等価変換**。位置とその鏡映に**同じ cp** を学習させる。
- **主指標(train/val の decisive 予測ギャップ)が縮んだ**:
  - baseline c5000: train 3202 / **val 1942**(ギャップ 1260)。
  - **mirror: train 3015 / val 2163(ギャップ 852, −32%)**。**val の度合いが train 側=正解側へ近づいた=汎化が上がった**。
- 併用指標も改善: **val_corr 0.75→0.80**、decisive 符号一致 0.81→0.83、best val_loss 1.40M→1.15M、過学習(epoch1 の train/val loss 差)はほぼ半減。
- **棋力(技巧2 Lv1, 1秒, 8局): 0-8 のまま**だが **avg_plies 64→79 と粘りが増加**(diag 対局は詰まされず60手打ち切りへ)。fd32 維持で**速度低下なし**(深さ 5.21)。
- **切り分け結論: 左右対称拡張は汎化ギャップを縮める(Task 035 の真因に効く)第一の手**。ただし単独では Lv1 を超えるには不足(ギャップは縮んだが閉じてはいない)。
  次は他の汎化策(dropout・埋め込み次元↓・データ量↑)を**この上に積む**。
- **採用モデルを更新**: `model_cp_mse_c5000_mirror`(fd32, mirror)。推論コストは不変(学習側のデータ拡張のみ。Rust/探索は無改修)。

## 1. 左右反転の実装と検証(正しさ最優先)

実装(`trainer/mirror.py`):
- `flip_sfen`: SFEN 各段のファイルを逆順にする盤面レベルの鏡映(地の文どおりの水平反転=正本)。
- `build_mirror_perm`: KP 特徴 35万次元の置換。鏡映は正規化(180度)と可換なので、正規化済みの玉位置・駒位置を `mirror_square((8-sq//9)*9+sq%9)` で反転、
  持ち駒は位置なし=玉位置のみ反転、手番特徴は不変。→ キャッシュ済み KP を gather 一発で反転でき、学習で高速に使える。

検証(`trainer/verify_mirror.py`、500局面 + Gikou):
- **perm の involution**: `perm[perm[i]]==i` が全 353486 で成立。
- **二経路一致**: 盤面反転→KP と 特徴空間 perm が**500/500 完全一致**(+合法性・77特徴・**駒/手番/持ち駒の同一性**・盤面 involution も全一致)。
  → 反転は正しい水平鏡映であることを二経路で証明。
- **技巧2 cp は鏡映で不変ではなかった**(mean|diff| ~298cp、近0で大きい)。ただし**詰みは保存**(mate→mate)。これは反転バグではなく、
  **技巧2 の KPP ヒューリスティック評価が左右対称に作られていない**ため。真の値は不変(詰み保存・二経路一致が示す)。
  → 拡張で両向きに **cp(orig)** を当てるのは、この技巧2の非対称ノイズを**対称化して除く**ことになり、むしろ望ましい。

## 2. データ拡張の組み込み(`trainer/train_nnue.py --augment-mirror`)

- train バッチの各局面を**確率0.5で perm 反転**(同じ cp)。**val は反転しない**(元の向きで測る)。
- ペア漏れ防止: 反転は各 split 内で生成されるため、元局面とその鏡映は同じ split に留まり、train/val 間に漏れない。
- 目標・構造・元データは不変(左右反転の追加だけ)。1エポック ~24s(拡張なしと同等、確率0.5の片側反転なので実時間増なし)。

## 3. 効果(主指標 = pred_dispersion の train/val ギャップ)

`trainer/pred_dispersion.py`(decisive=|target cp|≥1500、forward のみ):

| モデル | train 予測\|cp\| | **val 予測\|cp\|** | train/val ギャップ | val_corr | decisive_sign | best val_loss |
|---|---:|---:|---:|---:|---:|---:|
| c5000(拡張なし) | 3202 | 1942 | 1260 | 0.75 | 0.81 | 1.40M |
| **+ mirror(採用)** | 3015 | **2163** | **852(−32%)** | **0.80** | **0.83** | **1.15M** |

- **val の decisive 予測が 1942→2163 と正解(3915)側へ +11%**。train は微減(3202→3015)、結果 ギャップが 1260→852 に縮小。
- 過学習も緩和: epoch1 の train/val loss 差が c5000 ~763k → mirror ~309k とほぼ半減。val_corr・符号も改善。
- **汎化ギャップが縮む=Task 035 の真因(過学習)に効いた**。第一の汎化策として成功。

### 併用: nnue-diag(代表局面・探索)

- 代表局面の decisive 度合いが伸びた: 飛車得 静的 1097→**1904**(技巧2 2635)、探索 603→1055。中盤 静的 1731。
- 代表4局面の静的「分解能」は 2.22× と数字上は下がるが、これは**curated の near-equal 局面(平手初期/▲7六▲3四)が高めに出た**ため
  (val の |pred|_near 平均は 265 で c5000 の 284 と同等=母集団では near-equal は膨らんでいない。curated 特有のノイズ)。
  **頑健な指標(val の train/val ギャップ)が改善**しているのが本質。
- diag 対局(1局・別ライン)の符号一致は 18/27。c5000 の 21/21 は別局の一標本で、**母集団の val 符号(0.83>0.81)が頑健な指標**。

## 4. 棋力・回帰・スケール

- 棋力(`nnue-vs-gikou` Lv1, 1秒, 8局): **0-8**(c5000 と同じ)だが **avg_plies 64→79** と粘り増。diag 対局は詰まされず最大手数へ。**深さ 5.21**(fd32 維持で速度低下なし)。
- スケール/数値一致(`verify_nnue_rust`, mirror モデル): 最大誤差 **2.26e-06** < 1e-3, ok。**学習側の拡張のみ=Rust 推論・探索は不変**。
- 回帰: `cargo test` 16/16、perft 1〜5 完全一致、`selfplay` 完走、対 Random **20勝0敗**。Rust 無改修。

## 所見と次段

- **左右対称拡張は汎化ギャップを縮める(val decisive +11%、ギャップ −32%、val_corr +0.05、過学習半減)第一の有効策**。推論コストゼロ。**採用**。
- ただし**ギャップは縮んだが閉じていない**(val 2163 < train 3015 < 正解 3915)、棋力も 0-8。汎化はまだ伸ばす余地。

  - 教師データの量・多様性↑(volume。暗記しにくくする)。
  - 主指標は `pred_dispersion` の train/val ギャップ。
