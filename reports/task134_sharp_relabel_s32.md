# Task 134 — 激しい局面だけ WS-T S=32 で付け直す (学習あり)

日付: 2026-10-17〜18。マシン: 14700KF (Xubuntu, RTX 4060 Ti)。コード: `experiments/alphazero/t134_sharp_relabel_s32.py` (事前登録済み)。
結果: `~/binbo-shogi-data/logs/task134_results.json`, ログ `task134_20261017-234616.log` / `task134_relabel.log` / `task134_student.log`。

## 動機 (Task 133)
- 玉の周りに駒が集まった局面で binbo は手番側を物差しより楽観する (自玉の 2 マス以内の敵 +20cp/枚, 相手玉の 2 マス以内の自分の駒 +27)。
- そのうち攻めの楽観は教師 (WS-T + Gumbel MCTS S=8) から来ていて, S=32 にすると減る (+57 → +31)。
- → 該当する局面だけ S=32 で付け直せば, 生徒の楽観も減って強くなるかを確かめる。

## 方法 (事前登録どおり)
- 対象: Task 129 の学習データ 64M 行のうち, どちらかの玉の 2 マス以内に敵の駒が 3 枚以上ある行 (max(att2_stm, att2_opp) ≥ 3)。
- 付け直し: WS-T の Gumbel MCTS を S=32 で (従来 S=8)。それ以外の行のラベルは Task 129 のまま。
- 学習: Task 129 と同じ (静止局面 64M, lr 6e-5, Factorizer, 12 epoch, 左右反転)。ラベルだけ差し替え。
- 判定: 標準の物差し (tanuki- @2 万 / AobaNNUE @1 万, 候補は 10 万ノード, seed 20272001-08, 各 400 局 × 2) で採用 eval (task129) とのペア差。
  「強い」なら新しい seed で確認。

## 読み
- ラベルは狙いどおり動いた (激しい局面で手番側に約 100cp 辛く) が, 強さの差は測れる大きさにならなかった。向きはプラスだが, 採用を変えるほどの根拠はない。
- 激しい局面は全体の 1 割で, 対局の勝敗を分ける局面はさらに一部。ラベルの改善がそこへ届いても, 平均の強さへの影響は小さいのかもしれない。
- Task 103b (S=8 ≈ S=32 が全体平均では同等) とも矛盾しない: 局面を絞っても S を上げるだけの効果は小さい。
- Task 133 のもう一つの原因 (自玉の危険の軽視は教師ではなく学習の側, 教師 −56 に対し binbo +20) はこの付け直しでは触っていない。→ BACKLOG「教師から生徒への橋渡し」。

## 追加: 楽観は減ったのか (Task 133 の回帰をやり直す, 2026-10-18)
- 同じ 2,985 局面を Task 134 の生徒で 20 万ノード・1 スレッドで評価 (`t133_king_safety_probe.py evaluate --engines binbo binbo134`, 16 本並列で 77 秒)。
  結果 `~/binbo-shogi-data/work/task134/probe/` (`evals_merged2.tsv`, `analyze_*.txt`)。
- 再現性: 採用 eval を評価し直すと Task 133 の値と完全一致は 1,512/2,985。ずれの中央値 0, 90% 点 67cp, 平均 −0.5。
  エンジン 1 本で局面を続けて評価するので置換表が次の局面に残り, 局面の分け方 (8 → 16) で値が変わるため。
  → 比較は同じ実行で評価し直した採用 eval (binbo129re) と同じ局面どうしで行う。生徒どうしの差は中央値 48cp, 90% 点 147cp でこのずれより大きい。
- 差の回帰 (候補 − 採用 を同じ説明変数で回帰 = 係数の変化, 対局単位のブートストラップ):

| 特徴 | 教師 S=8 | 教師 S=32 | 採用 eval | Task 134 の生徒 | 生徒の変化 [95%] |
|---|---|---|---|---|---|
| opp_att2 (攻め) | +57 | +31 (−27) | +28 | +20 | **−7.8** [−17.5, +2.2] |
| stm_att2 (自玉の危険) | −56 | −58 (±0) | +21 | +16 | −5.2 [−13.6, +3.8] |
| (floodgate の局面だけ) opp_att2 | | | +34 | +24 | −9.7 [−22.2, +1.9] |

  ほかに有意な変化は stm_krank +14 [+1, +27] だけ (12 個のうち 1 個, 多重比較を考えると偶然の範囲)。
- 読み:
  - **攻めの楽観は少し減った (−8) が, 教師の変化 (−27) の 3 割ほどしか生徒に移っていない**。変化の幅は 0 をわずかにまたぐ (向きは全 4 組で減る側)。
  - 自玉の危険は, 教師が S=8 でも S=32 でも −57 と見ていて, 付け直しで教師側は変わっていない。生徒は +21 → +16 で, 教師との開き (約 70cp/枚) はほぼそのまま。
  - まとめ: 「楽観は減ったが強さに効かなかった」でも「まったく減らなかった」でもなく, **ラベルは大きく動いた (平均 −104cp) のに, 生徒の楽観は少ししか動かなかった**。
    生徒が教師の玉の危険の見方を受け取れていないという読み (Task 133) を, 別の側から支える。次の本命は BACKLOG「教師から生徒への橋渡し」。
