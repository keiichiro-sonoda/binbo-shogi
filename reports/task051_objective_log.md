# Task 051: 学習目標の決着 — cp 直接回帰 vs 標準WDL変換 — 結果ログ

目標: **今の段階(canonical-shared / fd8 / 先生=技巧2 depth8)で、cp 直接回帰と標準WDL変換の
どちらが棋力に効くかを実験で決着させる**。判断は度合いでなく**棋力**(両者は乖離していると判明済)。
測定: `nnue-vs-gikou <w> $GIKOU <level> <games> <seed> 320 6 12 1000 1000`、**1秒/手 固定**。

## 背景(なぜ)

- Task 033 で「sigmoid 飽和による度合い圧縮」を理由に cp 直接回帰へ切替。度合いは伸びた(56→70%)が、
  Tasks 047/050 で「度合い↑だが棋力が動かない」乖離が判明。
- 標準(Stockfish/やねうら王)は **WDL 勝率空間**で学習。大評価値は勝率で飽和=棋力に効かず、
  **0付近の精度**が効く。lambda で評価値の勝率と実際の対局結果を補間。
- Task 050 の WDL は `loss=(1-α)cp_MSE + α·BCE(result)` の**加算項**(別物)。本タスクは**勝率空間 MSE +
  scaling + lambda** の**標準 WDL** を新 objective `wdl` として実装し直して比較。

## 実装(Step 1, train_nnue.py)

- 新 objective `wdl`: `target = λ·sigmoid(eval/scale_cp) + (1-λ)·result_winrate`、`loss = MSE(sigmoid(forward), target)`。
  `--wdl-lambda`(既定1.0)、scaling は `--scale-cp` 流用。`cp`/`winrate`/`--wdl-weight` は不変。
- **Rust 変更なし**: `eval_to_int` は `EVAL_SCALE=600` 固定、forward は順序保存で eval に使われる。
  WDL の forward は飽和で ±10 程度(×600 < 詰み境界28000)。`scale≠600` は `info score cp` の affine ズレ
  (cosmetic)のみで手の選択=棋力に無影響。
- データ: `caches/wdl_2m_shared`(2M, depth8, eval cp + WDL ラベル。win 44.8%/draw 10.3%/loss 44.9%、
  eval 符号と勝敗が decisive の 76% 一致=手番側視点で正しい)。**全モデル同一データ・同一構造・同一 seed**。

## 決着(Step 3)

**今の段階(canonical-shared / fd8 / 先生=技巧2 depth8 / 2M)では cp 直接回帰が明確に勝つ。
学習目標は cp を維持する。**

- **棋力(主判断)**: Lv1 で cp 29.7% vs 最良 WDL(s600)18.2% = **+11.5pp**(96局で seed 雑音外)。
  Lv2 でも cp 16.7% vs 最良 WDL(s400)11.5% = **+5.2pp**。標準 WDL の全 scaling(400/600/800)と
  全 lambda(0.7/0.5)が cp に届かず。**lambda(実結果混合)が最弱**(9.7%/6.2%)。
- **「度合い↓でも棋力↑」の逆転は起きなかった**: WDL は decisive_sign(0.843–0.852)も棋力も cp(0.860)
  より下。度合いと棋力が**同方向**に cp を支持。Task 050 で疑った「学習目標が律速」説は否定され、
  度合い⇔棋力の乖離(Tasks 047/050)は**学習目標でなく別要因**(表現力 KP の限界 or 先生の質)に切り分けられた。
- **なぜ cp が勝つか(解釈)**: 技巧2 depth8 の eval は全 cp 域で強い順序信号を持ち、それを勝率へ圧縮する
  (WDL)と探索が使う順序情報を捨てる。lambda で 1 局面の最終結果(高分散)を混ぜると更に劣化。
  小ネット・中規模データでは「0付近重視」の WDL より、全域を素直に回す cp が良い。
- **8M 再生成は不要**(cp が勝ったため。計画の分岐どおり)。採用モデル model_shared_fd8_mirror_8m(cp)を維持。
- scaling/lambda の傾向(参考): WDL 内では λ=1 > λ<1(実結果混合は害)、scale は s600≈s400≈s800 で大差なし。

### 将来の再訪条件(BACKLOG)

この決着は**この構成・この先生での結論**。次の条件で最適な学習目標は変わりうる(再訪):
1. **表現力を上げた後**(HalfKA / KPP):0付近の精度が効く土俵になれば WDL が活きる可能性。
2. **先生を DL 系に変えた後**:WDL ネイティブな教師なら WDL 学習が整合。
3. **データを桁で増やした後**:大データでは勝率信号のロバスト性が効く可能性。

実装資産は残す(`--objective wdl` + `--wdl-lambda`、Rust 変更不要)ので、上記条件が来たら即再評価できる。
