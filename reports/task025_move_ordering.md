# Task 025: ムーブオーダリング(ハッシュムーブ)

## 結論

- ムーブオーダリングの第一歩=**ハッシュムーブ順序付け**を入れた(`src/search.rs`)。各ノードで TT の
  `best_move`(深さ条件なしで取得)を、合法手リストの**先頭に1手だけ移動**(残りは生成順のまま)。
  反復深化のルートにも適用し、前イテレーションの最善手を深い探索の手順先頭に置く。
- **三位一体(TT + 反復深化 + ハッシュムーブ順序)の相乗効果が出た**。削減は深いほど激増:
  - **中盤・深さ5: 103.6M → 12.7M ノード(−87.7%)、165.0s → 21.3s(−87.1%)**。
  - 累積(中盤・深さ5): 素朴αβ(Task 022)235.7s → 今回 21.3s = **約11倍速(−91%)**。作者が長考を
    体感した中盤深さ5が、約2.7分 → **約21秒**に。
- **正しさ**: 順序あり/なしで**最善手・評価値が完全一致**(αβ の値は手順に不変。全ベンチ局面・全深さで MISMATCH なし)。
- **品質**: 順序あり 対 なし(同深さ)の自己対戦は **統計的に互角**(下記)。対 Random 30戦30勝、詰みも正しく発見。
- スコープ厳守: MVV-LVA・キラー・ヒストリーは未実装(次段以降)。

## 仕様(`src/search.rs`)

- 各ノードで TT を probe したとき、`best_move` を**深さ条件なし**で順序付け用に取得(枝刈りは従来どおり
  `entry.depth >= depth` 条件)。= 1回の probe で「枝刈り(depth 条件)」と「順序付け(depth 条件なし)」を両取り。
- `best_move` が現局面で合法か(= 合法手リストに含まれるか)を確認してから先頭へ移動。**非合法なら無視**
  (TT のハッシュ衝突や手の不整合に対する保険)。`pos.legal_moves()` は `ArrayVec` なので
  `remove`+`insert` で「先頭へ1手」だけ移動し、残りの順序は保つ(NNUE は呼ばない軽量操作)。
- **ルートにも適用**: `root_search` がルートの hash move で順序付けし、探索後にルート結果を TT に store。
  反復深化の次イテレーションがそれを probe → **前の最善手を最初に読む**(相乗効果の本体)。
- フラグ化(`Opts { prune, use_tt, use_ordering }`)し、ベンチ/自己対戦で各機能を独立に切り替え可能に。

## 正しさ・品質

- **最善手・評価値一致**: 上のベンチ表のとおり、順序 OFF/ON で best move・score が全一致(全局面・全深さ)。
  αβ の最終結果は手順に不変で、順序付けは枝刈りのタイミングだけ変えるため。一致しなければ順序付けのバグ
  (非合法手を先頭に入れた等)だが、発生せず。
- **自己対戦(`nnue-ordmatch`, 順序 ON 対 OFF, 同深さ3, 乱数オープニング)**:
  - seed 20260621(100局): 45-50-5(45%)。seed 12345(100局): 49-49-2(49%)。
  - 合計 **94-99(決着193局)、約0.4σ下** = **統計的に 50% と差なし(互角)**。
  - 補足(正直に): 順序付けは**評価値・最善手スコアを変えない**が、**同点の手が複数あるとき**に選ぶ手が変わる
    (順序ありは hash move=前回最善手を、なしは生成順先頭を、それぞれ「最初に見つけた最善」として採用)。
    対局はこの同点手の選択違いで分岐するため、勝率は同点手の運で決まり 50% 付近に揺れる。**強さ(評価)では
    どちらも深さD最適**で、順序ありが弱いわけではない。小サンプル(初回40局 16-23)はこの揺れの範囲。
- **詰み発見**: ベンチ終盤で score=29997(MATE-3)を正しく出す(順序付けでも詰み・ply補正は不変)。
- **回帰**: 順序ありエンジン(深さ3)対 Random = 30戦30勝。`cargo test` 16/16、perft 1〜5 完全一致、
  `selfplay` 完走、option 無指定 USI は Random フォールバック、ビルド警告なし。

## 所見

- 反復深化の真価がここで出た。**TT(再計算削減)+ 反復深化(深さ間で最善手を継承)+ ハッシュムーブ順序
  (継承した最善手を最初に読む)** の三位一体で、中盤深さ5が約11倍速。
- ハッシュムーブは「best_move 1手を先頭へ」だけの軽量操作で、これだけで深い局面のノードを約88%削減。
  次段の MVV-LVA(取る手を価値順)・キラー・ヒストリーで、TT ミス時の残り手の順序も改善すれば、さらに伸びる余地。
